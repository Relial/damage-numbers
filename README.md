## Features

- Customizable damage numbers
- MMO style scrolling damage text
- Custom font selection by placing your desired font in bunny_fonts (.ttf /.otf)

## Requirements

[Bunny Manager](https://github.com/Relial/bunny-manager)

## Usage

Extract in the MHFZ game folder.

Configure in the manager's plugin menu.

## Known issues

Some damage sources won't display in multiplayer if you're not the area host.
